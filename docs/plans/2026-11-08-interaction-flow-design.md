# 页面交互前四项优化设计

以 origin/main ca3c117 为基线，在独立 worktree 的 codex/interaction-flow-improvements 分支实施。用户已授权实现、验证并直接推送。

1. 日程星期选择接入真实 toggleable，保留读屏名称与勾选语义。近期列表未来日期只预览，当日可打卡，过期的一次性事项继续允许补打卡；业务层校验日期，避免跨午夜误操作。每周至少选择一天。
2. 日程增加“近期 / 全部”视图。全部视图按事项展示所有记录，包含远期与已完成的一次性事项，提供重复规则及日期摘要；新增、修改后进入全部视图定位保存项。近期为空但已有记录时引导查看全部，避免误报没有日程。
3. 使用 SaveableStateHolder 分别保存顶层 Tab 和教务分区的状态，不引入额外导航依赖。保留滚动位置、展开状态，教室仅在实际更换楼栋时滚到顶部。系统返回先交弹层处理，再从教务/我的回课表，课表退出；设置、同步仍回到来源页。前后台课表定位和成绩隐私规则保持原约定。
4. 成绩与考试刷新直接进入限定范围，成功后自动回来源页并给出结果，失败保留汇总重试；沿用 WebView 登录与扫码能力。成绩范围只获取成绩、学籍和学业进度，不改课表、考试或云账号。完整同步仍由课表/云同步入口触发。云备份记录服务端返回的成功上传/恢复版本时间：同账号、已开启同步且云端仍是本机已确认版本时免方向确认；首次关联、远端改变或缺乏依据时仍询问，网络失败不自动上传。换账号清除旧版本依据。服务端会重新序列化 JSON，不能用上传原文摘要判断同一快照。

验证：JVM 日程日期/窗口/补打卡与同步范围/云决策测试；JS 成绩范围与失败测试；Compose 真实触摸、未来打卡、分区位置恢复测试；全量单测、lint、debug 构建、release R8。有可用模拟器时执行设备回归。最终提交并推送新分支，不合并主干、不发布正式版本。

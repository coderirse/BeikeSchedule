# 课程隐藏与考试刷新设计

已确认：隐藏时选择“仅本次 / 整个学期”；仅本次只影响所点卡片当天的一堂课及其提醒。连续隔周课标注“单周 / 双周”，单次课标注“第 N 周”，其他安排在详情查看。隐藏列表完整显示名称、来源、时段与范围。考试刷新仅获取考试，其他入口继续全量同步。

课程保留原始周次，新增按日期记录的隐藏例外。按真实日期过滤后再合并教务拆行，课表、下一节课、提醒共用此规则；补课日与原星期互不影响。整个学期仍按课程名与来源隐藏。恢复整个学期同时清除该组的日期例外；恢复单次只移除对应日期。重新导入和班级安排更新保留匹配时段的例外，云备份携带新字段，旧数据默认无例外。Room 以显式迁移升级，保留旧数据。

隐藏列表按整门课或具体日期与卡片分组，合并同一项的存储拆行。课程名称允许完整换行，辅助信息与恢复按钮分开布局。

考试页复用现有 WebView 登录能力，以独立同步范围运行身份核对与考试脚本，跳过云登录、课表、成绩、实验安排以及云恢复步骤。考试有独立更新时间。请求或解析失败保留旧考试及提醒，合法空列表清空旧考试并重排提醒。已开启的自动备份继续沿用原设置。

验证覆盖：日期隔离、补课、拆行、重新导入保留、恢复、提醒与下一节课、标签边界、旧快照兼容，以及考试范围与失败重试。运行 JVM 单测、debug 构建、lint 和 R8；有可用设备时进行界面检查。

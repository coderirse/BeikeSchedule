# 宠物 AI Implementation Plan

> 按用户已确认设计，在当前独立功能分支逐项实施并验证；用户随后明确授权提交、推送和发布 v2.1.0 / 67 供手机测试，继续当前分支。

**Goal:** 提供可自定义人格、有本机记忆、支持联网及授权学习分析的宠物。

**Architecture:** 保持 Compose → ViewModel → 只读工具 / 网络 / 独立加密存储。AI 状态不进入核心数据库或云快照，所有自动活动受课表生命周期约束。

**Tech Stack:** Kotlin、Compose Material3、Flow、OkHttp、kotlinx.serialization、AndroidKeyStore、JUnit、Compose 设备测试；不增加生产依赖。
